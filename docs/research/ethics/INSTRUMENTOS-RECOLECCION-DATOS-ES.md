# Instrumentos de recolección de datos

**Estudio:** TTOD-Strand-B-FEII-2026-27  
**Versión:** 2026-09-26  

## 1. Principio

Este estudio **no introduce** cuestionarios, baterías psicométricas, diarios de vida privada ni
entrevistas como instrumentos por defecto. La recolección investigadora es **uso secundario
seudonimizado** de artefactos ya producidos para la **evaluación ordinaria** de la asignatura,
tras consentimiento informado (ítem B).

---

## 2. Instrumentos activos en el diseño mínimo

| ID | Instrumento | Origen | Qué se recoge para investigación | Formato |
| -- | ----------- | ------ | -------------------------------- | ------- |
| **I1** | Historial de commits / pull requests | GitHub (o remoto equivalente del curso) | Narrativas de cambio, ciclos de revisión, comentarios técnicos seudonimizados | Texto / metadatos técnicos |
| **I2** | Declaración de uso de IA | Entrega / rúbrica FE II | Texto pedagógico sobre uso de herramientas; sin datos de vida privada | Texto |
| **I3** | Notas estructuradas de defensa oral | Evaluación (rúbrica / acta breve) | Respuestas a preguntas de diseño/explicación; **sin** audio/vídeo en el diseño mínimo | Texto estructurado |
| **I4** | Extractos de código / capturas no identificativas | Repositorio de la entrega | Solo si consentimiento de difusión (ítem F / C4); con seudonimización | Texto / imagen |

**Plantillas docentes de I2–I3:** las que ya fija la guía / encargo de la asignatura (adjuntar
extracto institucional a la remisión). Este anexo no sustituye la rúbrica oficial; declara su
**uso investigador**.

---

## 3. Instrumentos **no** activados (fuera de alcance de esta versión)

| ID | Instrumento | Estado |
| -- | ----------- | ------ |
| I5 | Cuestionario / encuesta de entrada-salida | **No** — N/A |
| I6 | Entrevista semiestructurada | **No** — N/A |
| I7 | Grupo focal | **No** — N/A |
| I8 | Grabación de audio/vídeo de defensa o entrevista | **No** — N/A |
| I9 | Telemetría IDE / keystrokes / prompts completos de LLM | **No** — fuera de alcance |

Si en el futuro se activara I5–I8, se presentará **modificación** al comité con el instrumento
completo y consentimiento ampliado (ítems D/E del formulario).

---

## 4. Procedimiento de recolección (investigador)

1. El alumnado produce I1–I3 como parte de la docencia (con o sin consentimiento investigador).
2. Tras dictamen ético y consentimiento B, el custodio / PI construye un corpus seudonimizado
   (códigos `P01…Pn`).
3. No se exportan calificaciones ni identificadores al corpus.
4. El análisis sigue el protocolo completo.

---

## 5. Validación de instrumentos

I1–I3 son **instrumentos auténticos de evaluación** ya comunicados al alumnado en la guía
docente; no son escalas nuevas inventadas para la investigación. Su validez para *aprender
haciendo* se discute como parte del caso, no como validación psicométrica previa.
